# Agentic Coding Power-User Track

**Target:** Become a genuine power user of agentic coding tools (Claude Code and similar) — not as a study topic on its own, but as a productivity multiplier applied to every project in this plan, starting week 1.
**Format:** Light-touch and ongoing, not a weekly time commitment like LeetCode. A handful of deliberate leveling-up moments, then default to using it well on everything after.

---

## Progression

### Weeks 1–2 — Daily-driver fundamentals
- Set up a `CLAUDE.md` for each project as it starts (P1 first) — orientation, not a full spec.
- Learn plan mode for anything non-trivial before writing code.
- Learn custom slash commands / skills for anything you'll repeat (e.g., a "log today's study session" command).
- Apply directly: scaffold P1 (nanoGPT) with this workflow rather than by hand.

### Weeks 3–4 — Subagents / multi-agent workflows
- Learn when delegating to a subagent beats doing it inline (independent research, parallel exploration, isolating noisy tool output from your main context).
- Apply directly: use it while building out P2's pipeline stages (embedding, retrieval, reranking, eval) — these are naturally parallelizable.

### Weeks 5–8 — MCP + orchestration
- Build a small personal MCP server — wrap something you actually want (e.g., a LeetCode progress tracker, a personal paper-notes search). This can be lighter-weight than Phase 3's formal MCP week and serve as a warm-up for it.
- Try a fuller multi-step orchestration (a workflow with several coordinated agents) on one real multi-step task from this plan — good candidates: building P3's multi-agent pipeline, or running the paper's lit-review sweep.

### Ongoing
- Default to using agentic coding for every project task in this plan, not just the "study" weeks above.
- Note what worked and what didn't in the weekly `log/` entry — this is how the workflow actually improves, not by reading more docs about it.
- Revisit and refine your own `CLAUDE.md`/skills setup periodically as you learn what you actually reuse.

## Why this is worth dedicated attention

You're job-switching into roles that will expect fluency with these tools, and every project in this plan (nanoGPT, RAG, multi-agent, fine-tuning, the paper itself) is a real opportunity to build that fluency instead of treating it as a separate thing to "study."
